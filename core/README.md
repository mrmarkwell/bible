# Core Engine (`core/`)

This directory contains the domain logic, scripture reference parsing, database models, schema migrations, and storage abstraction layers.

## Responsibilities
- Canonical reference parsing (book, chapter, verse, multi-verse ranges).
- SQLite database interaction, query generation, and indexing.
- Public domain scripture ingestion and storage.
- Encrypted/obfuscated storage provider for copyrighted translations.
- Semantic tagging, relationship edge queries, and topic density aggregations.
