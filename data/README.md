# Data Storage & Assets (`data/`)

This directory contains local SQLite databases, public domain text sources, schemas, and asset files.

## Directory Structure
- `db/`: Working SQLite databases (e.g. `bible.db`).
- `raw/`: Raw public domain translation text / json / xml files (e.g. World English Bible - WEB, King James Version - KJV).
- Root Dataset: [`favorite_bible_verses.csv`](../favorite_bible_verses.csv): User's curated collection of 829 biblical passages and 50 starred passages across the canon (`book,chapter,start_verse,end_verse,starred`).
